功能解析与使用教程
🌧️ 序言 · 声明
此小功能是个与 Char 一起看小说的。禁止二传倒卖，如发现有二传倒卖的，请联系耳机进行举报。
📖 1. 小说导入与书架管理
• 导入小说：首页右上角点击「+」，输入书名、作者，支持选择封面（不选则自动以书名生成极简封面），点击导入 TXT 文件。
• 超大长篇自动分章：支持几百万字小说分段处理（选择字数智能分卷并实时展示进度条），杜绝卡顿死锁。
• 分组与长按管理：左侧栏可点击「创建分组」；长按任意书籍可弹出菜单进行「移动分组」或「删除小说」。
👤 2. Char 与 User 人设库
• Char 人设：左侧抽屉进入，支持手动填写性格与恋人关系，或直接导入酒馆卡 PNG / JSON / TXT，自动解析人设。右上角「小房子」图标进入人设库（一排 5 个卡片，支持多选批量删除与修改）。
• User 人设：填写你的名字与性格，并选择「关联 Char」，右上角小房子进入人设库（一排 4 个卡片，标明关联伴侣）。
🌐 3. API 配置与世界书设定
• API 配置：输入接口 URL 与 Key，点击「拉取模型」即可下拉选取模型，支持温度调节（0~2）及「保存为 API 预设」。
• 世界书管理：需先在右上角创建分组，再创建世界书条目。阅读时绑定后，AI 将自动融合世界书设定进行剧情互动。
📱 4. 阅读器与伴读设定
• 顶栏/底栏呼出：点击正文区域或上下箭头可随时折叠/展开控制栏。
• 模式切换：顶栏支持「翻页阅读」与「长文下滑」一键切换，自带章节目录选择。
• 伴侣选择：底栏第一个图标「爱心」选择陪同看书的 Char 与 User，确认是否开启世界书。绑定后再次点击可随时开关世界书条目或重新选择伴侣。
• 阅读定制（齿轮）：支持导入背景壁纸、0~100% 模糊度调整（防白边设计）、一键「清除壁纸」、字号微调/键盘输入、调色盘改色、字体文件/URL 导入。
💬 5. 划线段评与 AI 多轮互动
• 剧情划线讨论：选中正文文字长按，再点一起即可弹出气泡「与char聊聊这段剧情」，即可进入段评区。
• 恋人纯对白回应：发送段评后，Char 会在正下方以恋人视角进行真诚/吐槽回复（严格禁用生硬的动作括号描写）。
• 多轮上下文连贯对话：点击 Char 回复下方的「回复」按钮，即可针对 Char 的观点继续追问互怼，AI 会完整读取前文多轮对话历史！
• ⭐ 五角星真实书粉讨论：点击右上角五角星，AI 将根据本段小说剧情实时生成带真实网名、长短评、梗评与楼中楼互动的路人段评。回复路人后，路人也会结合你的话继续回帖！
• 段落角标：关闭段评弹窗后，对应段落末尾会显示数字角标，点击即可随时重温讨论。
💾 6. 数据备份与跨设备互通
• 在侧边栏「数据保存」页面，点击「导出数据备份 (JSON)」可一键导出所有小说进度、人设、世界书与段评记录。
• 更换手机、平板或浏览器时，只需导入该 JSON 文件即可实现无损数据迁移与互通。
